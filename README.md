# Time-Sheet Application

A simple and efficient Node.js application backed by an SQLite database to track and manage daily work hours, tasks, and timesheets.

## Features
* Log daily work tasks and hours.
* Persistent data storage using a local SQLite database (`timesheet.db`).
* Dynamic server rendering using Node.js.

## Prerequisites
Before running this application, make sure you have [Node.js](https://nodejs.org/) installed on your computer.
